# Calculadora Inteligente

Este projeto é uma calculadora financeira desenvolvida em Python e Bash.

## Código em Python

O programa em Python solicita o nome do usuário e dois valores.
Depois, ele calcula:

- Soma dos valores;
- Diferença;
- Multiplicação;
- Divisão;
- Comparação entre os valores.

O programa também mostra uma mensagem final com o nome do usuário.

## Arquivo Bash

O arquivo `calculadora.sh` permite executar a calculadora no Linux.

Para executar o arquivo, é necessário dar permissão de execução com o comando:

    chmod 744 calculadora.sh

Depois, execute o programa com:

    ./calculadora.sh

## Objetivo

O objetivo deste projeto é praticar programação em Python, comandos Linux, Bash e utilização do GitHub.
